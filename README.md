This branch stores the validation metrics (`.txt` format), including Pearson's correlation, Spearman's correlation and MSE validation loss on the held-out dataset for each dataset tested. The best-performing models under the `CNN1-only` and the full `CNN1+CNN2+MLP+GNN` frameworks are analyzed. 

The `.ipynb` files include the corresponding figures in the article and the codes used to generate them.

# Installation guide
## Inside the modcrispr directory, switch to the "Performance-summary" branch
```bash
git switch Performance-summary
```
## then relaunch or refresh Jupyter Notebook
```bash
jupyter notebook
```
