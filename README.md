This branch stores the model-predicted reaction outcome for validation of each gRNA structural effect. 

The `.ipynb` files include the corresponding figures in the article along with the codes used to generate them. 

The `.txt` files contain the underlying data associated with these figures.

# Installation guide
## Inside the modcrispr directory, switch to the "Computational-struct-effect-validation" branch
```bash
git switch Computational-struct-effect-validation
```
