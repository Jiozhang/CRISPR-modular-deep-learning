Custom fine-tuning from your own dataset

Upload your own Excel dataset to fine-tune from the generalist model. The Excel file must contain 3 columns: guide sequence, target sequence, and activity value.

Suggested repeat_k: use 1 if sample size is over 1,000; use 10 if sample size is between 100 and 1,000; use 100 if sample size is below 100.
Suggested: use a smaller value for faster tuning. For example, 10–20 for quick runs.
Download template
Use the downloadable template to ensure the correct column order: guide, target, activity.
Column 1 = guide sequence (max 30 nt), Column 2 = target sequence (max 30 nt), Column 3 = activity value (0 to 1).
